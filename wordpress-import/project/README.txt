WORDPRESS IMPORT — "Pico-0: Getting Started with Raspberry Pi Pico" team project page

1. On the destination WordPress site, go to Dashboard > Tools > Import > WordPress
   (install the WordPress importer plugin first if prompted).
2. Choose "portfolio.xml" from this folder, then click Upload file and import.
3. When asked, assign the imported content to your own WordPress account.
4. The "Download and import file attachments" checkbox doesn't matter here —
   leave it either way, there's nothing for it to fetch.
5. Go to Pages > All Pages and open the new page (it imports as a draft).
6. For each gray "Add your photo here" block, delete it, then use the block
   inserter (+) to add an Image block and upload the matching photo from
   the images/ folder in this same zip — the placeholder text tells you
   exactly which filename to use.
7. Preview the page, then click Publish when it looks right.
